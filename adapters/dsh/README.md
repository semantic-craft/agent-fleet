# DSH native bridge plugin (`agent-fleet-dsh`)

A DSH desktop plugin whose only job is to expose the desktop Host's own Typert endpoints (`session/list`, `session/follow`, `session/prompt`, ...) on `~/.local/state/agent-fleet-dsh/native.sock` (directory 0700, socket 0600), for the Agenvo `dsh` connector ([ADR-0002](../../docs/decisions/0002-minimal-agenvo-fork.md)). Calls go through `ctx.typertGateway` with one owner Peer that never answers forwarded interactions; results and RemoteErrors come back unchanged. Replaces `dsh-grokbot-dispatch` / `hermes-dsh-dispatch` (2026-10-19), keeping only the native bridge.

Install or update: `node scripts/fleet.mjs release dsh`. It builds the pushed commit into `~/.local/share/agent-fleet/releases/dsh/<sha>/plugin`, points `releases/dsh/live` at it, links `agent-fleet-dsh` → `releases/dsh/live/plugin` in the desktop profile (replacing the older plugins), and waits for the bridge to answer from a new process. The desktop app reloads its profile when the profile changes; a code-only update needs DeepSeek Harness to be reopened. Then set the `dsh` instance endpoint to `unix://$HOME/.local/state/agent-fleet-dsh/native.sock` and re-approve the instance in the relay (runbook "日常操作").
